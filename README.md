# Verde-Flora
Site de venda de flores trabalho senai
Projeto: Verde Flora
Integrante: Ana Luiza Guimarães de Almeida
Curso: Informática para internet sala 2D
Professor: Josué Rodrigo Evangelista Figueirêdo

Apresentação do Projeto
O projeto é um site criado por HTML e CSS que tem como objetivo facilitar a venda de flores e a personalização de buquês. Esse site tem como objetivo ajudar pessoas idosas ou jovens adultos a comprar flores de forma mais simples e fácil, com entregas a domicílio para eventos ou presentes, facilitando a vida das pessoas que não tem tempo ou disponibilidade de ir em uma floricultura.

Funcionalidades
O usuário tem a possibilidade de navegar entre as três páginas do site, cadastrar-se no site e design intuitivo e amigável.

Tecnologias utilizadas
Foram utilizadas para a criação desse site, o Visual Studio Code, o Figma, HTML, CSS.

Estrutura do projeto
Foi utilizada uma pasta geral que comportava duas outras pastas e o Visual Code. Essas duas pastas eram o código do Visual com o HTML e CSS, e uma pasta separada com todas as imagens utilizadas.

Como executar o projeto?
Para executar o projeto a pessoa precisa possuir o Vscode e uma extensão dentro do vscode, chamada Live Server. A pessoa precisa abrir o código dentro do vscode, instalar o live server, assim que instalado a pessoa clica com o botão direito do mouse em cima da pasta do código e clicar em “abrir com live server”, assim o código abrirá uma pasta em um navegador.
